# 表达力训练营 🎙️

一个纯前端的表达力训练网站，无需安装、无需联网、无需 API Key——语音识别与全部分析都在浏览器本地完成。

## 启动方式

任选其一：

```bash
# 方式一：电脑本机使用
py -3 -m http.server 8347

# 方式二：手机访问模式（同一 Wi-Fi，打印手机可访问的地址）
start-phone.bat        # 或 py -3 serve.py
```

然后浏览器打开 http://127.0.0.1:8347/

> **在手机上使用**：支持 PWA（添加到主屏幕当 App 用）。三种方案与语音识别的手机支持情况，详见 **[手机使用指南.md](手机使用指南.md)**。
> 推荐使用 **Chrome / Edge**（语音识别 Web Speech API 仅在这两家浏览器完整支持）。
> 直接双击 index.html 也能使用，但语音功能因浏览器安全策略可能受限，建议走本地服务。

## 四大训练模块

| 模块 | 内容 |
|------|------|
| 🔥 朗读热身 | 24 段分级绕口令 + 12 篇经典美文：生僻字注音释义、TTS 范读、**逐句跟读模式**（听一句跟一句、逐句相似度打分）、整段挑战（相似度 + 语速分析）；48 个表达主题成语（释义/出处/例句/场景应用 + 看词选义小测 + **错题本**自动收录） |
| 🧭 条理表达 | 三页签：**🎯 情景训练**（32 道情境题 × 18 种方法，题目含身份/情境/推荐方法，作答后逐项分析 + 参考作答思路 + 参考答案）；**🧪 方法练习**（18 种方法的结构讲解 + 示例拆解 + 环节识别小测）；**🗂 题目库**（全部题目搜索浏览、一键开练）。训练页随时「📖 回顾法则」，忘词可跳转方法练习；支持 ⏱ 限时挑战 |
| 🔁 复述训练 | 12 篇科普短文，支持两种模式：**阅读复述** 与 **🎧 听读模式**（隐藏原文、只听一遍播报后复述，最接近会议场景）；分析要点覆盖率、开头点题、结尾收束、要点顺序与偷看次数 |
| 🎯 临场说服 | 14 个随机场景与"对方"多轮对话，每轮即时反馈 6 项说服技巧；回应乏力时对方会**追问施压**；结局随表现变化，附参考策略与示范对话 |

## 通用功能

- 📊 首页训练统计：最近 14 天训练柱状图、模块分布与平均分、连续打卡天数
- 🌙 深色模式（顶栏切换，自动记忆）
- ⬇ 训练记录导出 JSON / 一键清空
- 🎙️ 语音输入（Chrome/Edge）+ 全站 TTS 语音播报，不支持时自动降级为打字输入

## 语音使用须知 / 故障排查

- **长录音自动断开**：Chrome 的语音识别每 30~60 秒会断开一次流连接，本站已做自动重连续录（瞬时网络错误静默恢复，不弹错误）；只有权限被拒、无麦克风、网络持续不稳（30 秒内失败 8 次以上）才会提示。
- **每次都要重新允许麦克风**：权限弹窗请选择「允许」（部分浏览器显示为"每次访问时允许"），不要选"仅本次"。若已被设置成每次询问：点浏览器地址栏左侧 🔒 → 「网站设置」→ 麦克风 → 「允许」，一次设置长期生效。
- 麦克风权限状态会显示在录音面板上（已授权 / 待授权 / 被拒绝），被拒绝时按提示操作即可。
- 若使用浏览器内置预览窗（无独立配置的 WebView），授权可能不被记住，建议在正式的 Chrome / Edge 窗口打开本站。

## 技术说明

- 零依赖纯静态站：HTML + CSS + 原生 JS（9 个脚本文件，约 2000 行）
- 语音输入：Web Speech API（`webkitSpeechRecognition`，连续识别 + 自动重启），不支持时自动降级为打字输入
- 语音播放：SpeechSynthesis TTS（绕口令/美文范读、说服场景对方台词）
- 分析引擎：本地正则 + 结构检测（`js/analyzer.js`），包括 bigram Dice 相似度算法
- 训练记录：localStorage 本地保存（最近 100 条）
